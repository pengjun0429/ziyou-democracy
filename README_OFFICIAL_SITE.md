# 資優民主國官方網站

公開首頁已整理為《資優民主國法規全書》入口，保留既有的國民管理與文件管理頁面。

首頁提供：

- 修訂版《資優民主國憲法》全文，重新編排為 17 條，補上平等、人格尊嚴、正當程序、司法救濟、非常時期與修憲門檻。
- 超憲法、憲法、法律與行政命令四級法規索引。
- 法規關鍵字搜尋、位階篩選與建國沿革時間線。
- 官方公報式視覺，繁體中文、響應式手機版與原始 HackMD 編纂文件連結。
